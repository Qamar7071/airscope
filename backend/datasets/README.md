# Bundled datasets

Everything in this folder was created for AirScope and is released with the
project. These files make the platform run offline. **They are approximations for
demonstration, not authoritative data.**

| File | What it is | How it was made |
|---|---|---|
| `city_boundaries.json` | Analysis domain, centre and modelling settings for each city | Hand-digitised simplified polygons around each built-up area (Islamabad's domain includes the adjoining Rawalpindi urban area, one airshed). Not administrative boundaries. |
| `demo_stations.json` | Locations of *simulated* monitoring stations | Plausible sites chosen to mirror a common real-world pattern: monitors concentrated in central or affluent districts, dense peripheral districts unmonitored. Not real stations. |
| `localities.json` | Locality names with approximate coordinates | Compiled from general geographic knowledge for labelling only; typical error 0.5-1 km. |
| `synthetic_city_profiles.json` | Parameters of the synthetic nature run: population kernels, terrain features, November climate, illustrative emission sources | Illustrative values chosen to produce physically plausible patterns. Not an emission inventory, census or climatology. |
| `population_density.csv` | Population density lattice (people/km²) | Generated by `python -m data.demo_generator` from the locality kernels in the profile (soft-maximum overlap, low-density parks/lakes, uninhabited hill slopes). |
| `elevation.csv` | Elevation lattice (m) | Generated by the same command from a simple terrain model: a base gradient plus the Margalla Hills ridge (Islamabad), the Ravi floodplain (Lahore) and the Orangi/Manghopir hills (Karachi). |

The demo datasets in `backend/cache/<city>_demo.json` are generated from these
files and are **synthetic samples** of the nature run (see
`docs/methodology.md`, section 9).

## Reproducibility

Generation is deterministic (fixed seeds, no dependence on the current date).

```bash
cd backend && .venv/bin/python -m data.demo_generator --check
```

## Replacing with real data

Keep the column names and replace the rows: see `docs/adding_a_city.md` and
`docs/data_sources_and_licensing.md` for suggested open sources (WorldPop/GHSL,
Copernicus DEM, official boundaries).
